# bhc.arcanist.sh-docs

The documentation for [bhc](https://github.com/arcanist-sh/bhc), the Basel Haskell Compiler,
served at **[docs.arcanist.sh/bhc](https://docs.arcanist.sh/bhc/)**: installation, the quick start,
GHC compatibility, runtime profiles, targets, the compiler, runtime and standard library internals,
and the generated standard library [API reference](https://docs.arcanist.sh/bhc/api/).

The product page, status, roadmap, playground and blog are on [arcanist.sh/bhc](https://arcanist.sh/bhc/)
(in the arcanist.sh website repository).

## Working on it

Built with [Zola](https://www.getzola.org/) **0.22** (`mise install` sets it up; newer Zola releases
reject the config).

```bash
zola serve    # http://127.0.0.1:1111
zola build
```

```
config.toml        site config: nav, footer and lockup = "bhc"
content/docs/      the pages; front matter title, description, weight
static/api/        the API reference, generated by bhc-docs from the bhc repository
themes/purple-haze/ the docs theme, shared with hx.arcanist.sh-docs (keep the two copies identical)
```

Every page should match the current compiler: run code samples with a current bhc and compare their
output with GHC before publishing them, and link known gaps to their
[issues](https://github.com/arcanist-sh/bhc/issues).

## How it is published

A push to `main` triggers the [docs.arcanist.sh](https://docs.arcanist.sh) build, which clones this
repository and builds it under `/bhc/`. The API reference in `static/api/` is regenerated by the
`docs.yml` workflow in the bhc repository whenever the standard library changes.
